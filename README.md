# Lucas & Joyce 💛

Landing page romântica em formato de álbum de fotos do casal: contador de tempo juntos, contagem regressiva para a próxima data especial, linha do tempo de momentos, galeria de fotos e formulário para irem guardando novas datas e memórias.

## Como usar

Abra `index.html` no navegador (ou publique com GitHub Pages).

- **Data de início do namoro**: preencha no formulário "Início da nossa história" para o contador funcionar.
- **Adicionar momentos**: use o formulário "Guardar um novo momento" para registrar datas, viagens, aniversários e marcos, com foto opcional.
- Tudo é salvo no `localStorage` do navegador — os dados ficam só no aparelho/navegador usado para cadastrar.

## Publicar no GitHub Pages

1. Vá em Settings → Pages no repositório.
2. Selecione a branch principal e a pasta raiz (`/`).
3. O site fica disponível em `https://<usuario>.github.io/<repositorio>/`.

## Estrutura

```
index.html      -> estrutura da página
css/style.css   -> estilos
js/script.js    -> lógica (armazenamento, timeline, galeria, contadores)
```
